### 2. Networking Fundamentals

A computer network connects devices so they can communicate and share information.

Important concepts include:

- **IP address:** Identifies a device or network interface on an IP network.
- **DNS:** Translates domain names into IP addresses.
- **HTTP and HTTPS:** Protocols used for web communication. HTTPS protects communication using encryption.
- **TCP:** Provides reliable, ordered data delivery.
- **UDP:** Provides connectionless data delivery without TCP's reliability guarantees.
- **Ports:** Help identify services or applications communicating over a network.
