## 1. Learning Notes

Today I learned about system logs and monitoring and how they help administrators understand what is happening on a computer.

**1. System Logs**

System logs are records of events generated by the operating system and applications. They help identify errors, understand system activity, and investigate unusual behavior.

Examples of information recorded in logs include:
- System startup and shutdown events.
- Application errors and warnings.
- Service activity.
- Hardware or software problems.
- Network-related events.

On Linux systems, logs are commonly stored in locations such as `/var/log/`.

**2. Authentication Events**

Authentication logs can contain records related to login activity and account access.

Examples include:
- Successful login events.
- Failed login attempts.
- Authentication errors.
- Administrative access activity.

Monitoring these events can help identify unusual login patterns that may require investigation.

**3. Monitoring**

Monitoring means regularly checking system activity and important events to identify problems or suspicious behavior.

Examples:
- Looking for repeated failed login attempts.
- Checking whether important services are running.
- Reviewing system warnings and errors.
- Comparing unusual events with normal system activity.

Some useful Linux commands for learning about logs include:

```bash
journalctl
journalctl -n 20
journalctl -p warning
```

These commands can display system journal entries, show recent entries, and filter entries by priority.

Another useful command is:

```bash
ls /var/log/
```

It lists the contents of the system log directory.

## 3. Key Takeaways

- System logs record events from the operating system and applications.
- Authentication records can help identify unusual login activity.
- Repeated failed login attempts may deserve further investigation.
- Monitoring helps administrators notice errors and unexpected behavior.
- Logs are useful for troubleshooting and security investigations.

**Important commands to remember:**

```bash
ls /var/log/
journalctl -n 20
```

These commands help locate log files and view recent system journal entries.

**Important lesson:** Logs provide useful evidence about system activity, but individual events should be interpreted in context rather than treated as proof of an attack.
