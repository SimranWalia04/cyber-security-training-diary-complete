## Learning Notes

Authentication is the process of verifying the identity of a user before allowing access to a computer system, application, or account.

Strong authentication helps protect personal information and prevents unauthorized access.

### 1. Unique Passwords

A password is a secret combination of characters used to access an account.

Good password practices include:

- Use a different password for every account.
- Choose long and difficult-to-guess passwords.
- Avoid personal information such as birthdays or names.
- Never share passwords with other people.
- Change a password if it is exposed or compromised.

Using unique passwords is important because if one account is compromised, other accounts remain better protected.

### 2. Password Managers

A password manager is an application that securely stores and manages passwords.

Its benefits include:

- Generating strong, unique passwords.
- Storing passwords in an encrypted vault.
- Reducing the need to remember many passwords.
- Helping prevent password reuse.

A password manager should be protected with a strong master password and available security features.

### 3. Multi-Factor Authentication (MFA)

MFA adds another verification step when signing in to an account.

Common authentication factors include:

- **Something you know:** A password or PIN.
- **Something you have:** An authenticator device or security key.
- **Something you are:** A biometric characteristic, such as a fingerprint.

For example, an account may require a password and a verification code from an authenticator application.

MFA makes accounts more difficult to access without authorization, even if a password is exposed.

### 4. Authentication and Authorization

These terms have different meanings:

- **Authentication:** Confirms who a user is.
- **Authorization:** Determines what an authenticated user is allowed to access or do.

Both are important parts of access control.

## Key Takeaways

- Every account should have a unique password.
- Long, unpredictable passwords are harder to guess.
- Password managers help securely organize passwords.
- MFA adds another layer of account protection.
- Authentication verifies identity, while authorization controls access.
- Passwords, recovery codes, and authentication secrets should never be shared publicly.

**Security principle to remember:** Never reuse passwords across important accounts, and enable MFA whenever it is available.
