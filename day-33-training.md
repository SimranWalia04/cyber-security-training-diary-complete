## Learning Notes

Today I studied Markdown and how it helps create readable documentation for projects on GitHub.

Markdown is a lightweight markup language that uses simple symbols to format text. GitHub supports Markdown, especially in README files and project documentation.

Important concepts:

1. **Headings:** Use the `#` symbol to organize information into sections. More `#` symbols create smaller headings.
2. **Lists:** Use hyphens (`-`) for unordered lists and numbers for ordered lists.
3. **Code blocks:** Use three backticks to display commands or code clearly.
4. **Bold and italic text:** Use asterisks to highlight important words.
5. **Links:** Use Markdown link syntax to reference useful websites or project resources.

Examples related to my AES project:

**Heading:**
```markdown
# AES Encryption Project
## Features
### Testing
```

**List:**
```markdown
- File encryption
- File decryption
- Authentication checks
```

**Code block:**
```bash
python3 --version
git status
```

These examples show formatting syntax. The commands are reference examples, not confirmation that I executed them.

## Key Takeaways

- Markdown makes project documentation easier to read.
- Headings create a clear document structure.
- Lists organize features, steps, and notes.
- Code blocks display commands and code without mixing them into normal paragraphs.
- **Important lesson:** Good documentation helps other people understand a project without needing to inspect every source-code file.
